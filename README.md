# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 阈值试算发布（`/thresholds`）：按候选阈值与原始读数计算新增/消失/升级/降级/保留差异，试算不覆盖复核、审批与审计；试算期间接入新读数或再次改版阈值，旧候选失效并按最新快照重算；确认后整批切换阈值版本与异常结果，写入失败保留原数据、重试只补未生效项；已关闭异常保留当时依据并列入差异；页面与JSON审阅包显示同一批次。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- JSON审阅包导出。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
